# 用户指南

## 客户支持云是什么

不是工单系统。工单系统优化吞吐量，关单即终点，知识死在关闭的工单里。客户支持云的一等实体是**问题 → 解决方案**：每次服务结束，留下的不是一单归档，而是一条可复用的资产。

## 核心循环

使用方式就是走完这个循环：

1. **提问**——问题进来（客户发起或支持人员录入）
2. **AI 应答**——AI 先用已积累的资产（解决方案库 + 蒸馏规则）尝试回答
3. **升级人工**——AI 答不了的，升级到支持人员；人给出真正的解决
4. **蒸馏沉淀**——人的解决被蒸馏回资产库：解决方案条目、诊断规则、甚至支持智能体
5. **复用**——下一个同类问题，AI 直接答掉，不再需要人

这个循环跑得越久，无需人参与的比例越高。人从回答者变成兜底者和老师。

## 你会积累到什么

| 资产 | 说明 |
|---|---|
| 解决方案库 | 问题→答案的配对加诊断路径，核心一等资产 |
| 蒸馏规则 | 从交互中提炼的诊断树、路由规则、升级判据、支持智能体 |
| 需求与缺陷信号 | 请求和抱怨结构化后喂给需求地图——支持是法源的传感器 |
| 原始交互档案 | 全部对话留档，是蒸馏的语料和审计依据 |

## 用得好不好怎么看

不看关单数，看两个数：

- **无需人参与的比例**——AI 直接答掉的问题占比
- **复用率**——一条解决方案被多少后续问题命中

管理者的入口是资产视图：复用率、高频问题榜。如果高频榜上有一条问题反复靠人解决而没沉淀出解决方案条目，就是循环在哪里断了。
